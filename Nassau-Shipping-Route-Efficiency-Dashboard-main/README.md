# 🚚 Factory-to-Customer Shipping Route Efficiency Dashboard

## Overview

An interactive logistics dashboard built using Python, Streamlit and Plotly to analyze shipping performance, route efficiency and logistics KPIs.

## Features

- Interactive KPI Cards
- Route Analysis
- Ship Mode Analysis
- Geographic Analysis
- Business Insights
- Download Filtered Data

## Tech Stack

- Python
- Pandas
- Streamlit
- Plotly
